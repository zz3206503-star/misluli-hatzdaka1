העלאה ל-GitHub:
1. חלץ את קובץ ה-ZIP בטאבלט דרך My Files (הקבצים שלי) ואז Extract (חלץ).
2. היכנס למאגר misluli-hatzdaka1 בחשבון zz3206503-star.
3. בחר Add file (או + ליד רשימת הקבצים), ואז Upload files.
4. העלה יחד את שבעת הקבצים הבאים לאותו מקום שבו נמצא index.html:
index.html
pwa.js
sw.js
manifest.webmanifest
icon-180.png
icon-192.png
icon-512.png
5. בחר Commit changes. אין צורך למחוק קודם את index.html הישן.
אין להעלות את קובץ ה-ZIP עצמו ואין להעלות את הקבצים בתוך תיקיית משנה.
אפשר להשאיר את READ-ME.txt מחוץ לאתר.

התקנת PWA:
במסך הבית לחץ 'התקנת אפליקציה — PWA' ואשר בדפדפן.
אם לא מופיע חלון התקנה, הכפתור מציג הוראות להתקנה דרך תפריט הדפדפן.
באייפון משתמשים ב-Safari ובתפריט השיתוף. במחשב האפשרות תלויה בדפדפן.

קיצור דרך:
לחץ 'יצירת קיצור דרך' לקבלת הוראות. ב-Chrome באנדרואיד:
⋮ > Install and create shortcut > Create shortcut > Add
בגרסאות אחרות: Add to Home screen > Create shortcut.
זהו קיצור דרך רגיל שנפתח בדפדפן. שמות האפשרויות תלויים בגרסת הדפדפן.

לאחר טעינה ראשונה מוצלחת ניתן לפתוח את הממשק והנתונים השמורים גם ללא רשת.

זו אפליקציית אינטרנט מותקנת, לא פרסום בחנות Google Play.
